# Portal Analytics Dashboard Frontend

Отдельный frontend для внешнего WEB-режима владельца PRO.

Цель папки — развивать standalone-режим рядом с текущим приложением внутри
Битрикс24, не меняя его поведение.

## Границы текущего каркаса

- backend остается общим;
- текущий `frontend/` не импортируется и не меняется;
- внешний frontend обращается к backend через `VITE_API_BASE_URL`;
- спорные продуктовые решения из ТЗ не зашиты в код;
- API `/api/dashboard/owner/bootstrap/` пока является контрактом для следующего
  backend-этапа.

## План подключения

1. Добавить backend endpoints для внешнего режима.
2. Подключить сохраненные отчеты владельца.
3. Переиспользовать существующий интерфейс отчета для desktop-режима.
4. Добавить кнопку перехода в WEB-версию в текущем Bitrix-приложении.
